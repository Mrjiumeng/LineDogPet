# 线条小狗桌宠

# LineDogPet
LineDogPet 是一款极简零负担、支持AI自定义、拥有丰富交互能力的创新线条小狗桌面宠物。项目最初仅为个人娱乐开发，许多朋友体验后希望可以下载使用，因此开源分享，仅供学习交流！

程序支持一键安装部署，内存占用极低，后台常驻也不会拖累电脑。默认纯本地离线运行，全程无广告、无后台偷偷上传数据，使用时几乎感知不到它的资源消耗。内置桌面智能感知模块，能够识别窗口状态，支持全屏自动隐藏、窗口智能避让，打游戏、看视频时不会遮挡画面。项目会长期维护，持续迭代新增功能与修复问题。

自带完整鼠标交互体系，线条小狗可以感知鼠标位置，做出躲避、跟随、蹭光标等多种趣味动画反馈，摆脱传统桌宠只会来回走动的单调效果，互动感更强。

AI对话功能为可选扩展，**默认不启用、不联网，不加载**。用户可以自行填入私人API密钥、接口地址和模型名称，按需开启智能对话。项目不内置任何付费大模型服务，不会强制联网，密钥由用户自行保管，所有权限完全交由用户掌控。

开放多项自定义选项，你可以自由调整宠物显示大小、动画播放帧率、开启/关闭音效。代码结构清晰，拓展门槛低。可以作为桌面解压美化小工具，如二次开发请注明原作者。

## ✨核心亮点
- 🧊 **极致轻量**：一键安装，常驻内存占用极低。办公、编程、游戏场景后台静默运行，不占用大量系统资源，不会造成卡顿。
- 🐾 **智能感知**：实时感知桌面与窗口状态，支持全屏自动隐藏、窗口智能避让，减少对屏幕内容的干扰。
- ✨ **鼠标交互**：实时响应鼠标移动、点击操作，触发丰富动态互动动画，可玩性远高于普通桌面宠物。
- 🤖 **自选AI赋能**：优先本地离线运行，不填API完全断网使用；用户自备API接口，按需解锁智能对话功能，无任何捆绑收费。
- 🎛️ **高度自定义**：宠物尺寸、动画帧率、音效开关均可自由调节；项目纯净开源，支持自由二次开发与素材替换。

## 📅 开发规划（Roadmap）

- 新增 Mini 双人模式，支持双人远程互动玩法
- 新增**行为记忆习惯学习系统**：本地轻量学习用户电脑使用习惯，数据仅保存在本机几十 KB JSON 文件，不上传。根据作息、使用场景自适应宠物行为；同时记忆用户交互偏好，习惯改变后宠物行为自动调整，支持一键重置学习记录。
- 新增**窗口跟随陪护模式**：右键绑定指定应用窗口，宠物跟随目标窗口一起移动；窗口最小化自动隐藏，还原窗口重新显示；取消绑定恢复自由游走。
- 新增**全局热词本地触发动作**：手动读取剪贴板，用户自定义关键词，复制对应文字触发专属宠物动画；无需 AI 即可使用。
- 新增**截图捕捉轻量化联动（可选开关）**：不会自动截图，快捷键 + 点击宠物手动触发，宠物弹出截图缩略气泡；开启 AI 后可调用 API 描述截图内容，关闭 AI 仅展示图片，全程不私自抓取屏幕。
- 持续扩充动画库，优化交互逻辑，提升动画流畅度
- 完善配置面板，增加更多自定义选项
- 修复已知 bug，提升程序稳定性
