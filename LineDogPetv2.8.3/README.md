## ✨ 特性亮点

### 🐕 小狗日记与里程碑
- **实时每日日记**：小狗会自动记录每天发生的趣事、心情变化，生成温馨的日记本
- **里程碑「第一次」**：收集各种「第一次」事件，解锁专属称号与小惊喜
- **养成式记录**：见证成长的点滴，记录你和小狗的每一个重要时刻

### 🎭 可爱的桌面伙伴
- **多个可爱角色**：小白、小鸡毛
- **丰富动画状态**：空闲、行走、睡觉、开心、摸头、抱起、转圈、追逐、躲猫猫等 20+ 种状态
- **自定义外观**：可调节宠物大小（80-260px）、动画帧率（流畅/均衡/普通/省电）
- **精美气泡对话框**：支持自定义文字颜色和显示时长

### 🖱️ 丰富的鼠标交互
- **轻点摸头**：左键单击宠物的头部，它会开心地回应
- **长按抱起**：长按拖拽可以抱起宠物，带它到桌面任何地方
- **右键挠下巴**：右键点击会挠下巴，让宠物感到舒适
- **双击呼唤**：双击宠物可以呼唤它过来
- **画圈转圈**：按住鼠标画一个小圆圈，宠物会转圈撒娇
- **甩动追逐**：快速甩动鼠标，小狗会兴奋地追逐
- **滚轮对话**：中键点击可以和宠物对话

### 🧠 智能系统感知
- **闲置检测**：3分钟无操作自动入睡，长时间闲置会蜷成一团
- **全屏检测**：全屏游戏/演示时自动缩小躲到屏幕角落
- **编程陪伴**：检测到代码编辑器时安静陪伴
- **浏览器偷看**：在浏览器中会探头偷看内容
- **CPU 负载感知**：高负载时紧张踱步，低负载时放松，并自动降帧省资源
- **剪贴板感知**：读取复制的文本，弹出小纸片提示（不上传）
- **时间感知**：白天活泼、傍晚慵懒、夜里犯困

### 🎮 趣味小游戏
- **追小球**：宠物会追逐虚拟小球，充满活力
- **躲猫猫**：宠物会躲到屏幕边缘，让你找它
- **喂食互动**：通过托盘菜单喂食，增加体力
- **陪玩互动**：陪宠物玩耍，提升心情

### 🤖 AI 对话功能（可选）
- **多平台支持**：支持 DeepSeek、豆包、OpenAI、自定义 API
- **隐私保护**：请求直接发送到你配置的服务商，不经过中间服务器
- **上下文感知**：可选将本地状态（时段/CPU/在写代码等）作为对话上下文
- **本地指令**：支持"变大/变小"、"躲猫猫"、"追球"等语音指令
- **不开启零网络**：AI 功能默认关闭，不开启时完全不联网

### 🎯 智能桌面管理
- **智能避让**：自动跑到没被窗口挡住的空白桌面
- **随机闲逛**：空闲时在桌面空白处自然走动
- **角落锁定**：可固定在屏幕四角之一
- **全局快捷键**：一键隐藏/显示宠物（默认 Ctrl+Alt+D）
- **开机自启**：支持开机自动启动

### 🔧 系统特性
- **低内存占用**：即用即弃的 GIF 加载策略，内存占用仅几十 MB
- **自动内存回收**：定期清理缓存，保持系统流畅
- **自动更新检查**：启动时自动检查新版本
- **绿色软件**：无需安装，双击即可运行
- **配置持久化**：自动保存位置、心情、体力等状态

## 🚀 快速开始

### 系统要求
- **操作系统**：Windows 10/11
- **Python**：3.8 或更高版本
- **依赖库**：PyQt6

### 安装步骤

1. **下载程序**
   ```bash
   # 从 GitHub Releases 下载最新版本
   https://github.com/Mrjiumeng/LineDogPet/releases/
   ```

2. **解压运行**
   ```bash
   # 解压后双击运行
   智能桌宠.exe
   ```

3. **或从源码运行**
   ```bash
   # 克隆仓库
   git clone https://github.com/Mrjiumeng/LineDogPet.git
   cd LineDogPet

   # 安装依赖
   pip install -r requirements.txt

   # 运行程序
   python 智能桌宠.py
   ```

### 基本使用

1. **托盘菜单**：右键点击系统托盘图标打开菜单
2. **设置面板**：选择"设置…"打开详细设置
3. **状态面板**：选择"迷你状态面板…"查看心情和体力
4. **快捷键**：按 `Ctrl+Alt+D` 快速隐藏/显示宠物

## ⚙️ 详细配置

### 形象与声音
- **宠物形象**：选择小白或小鸡毛
- **显示大小**：80-260px 可调
- **动画帧率**：流畅/均衡/普通/省电
- **音效开关**：开启/关闭叫声和音效
- **整点报时**：每小时轻轻叫一声
- **气泡设置**：自定义文字颜色和显示时长

### 鼠标交互
- **交互开关**：开启/关闭所有鼠标交互
- **跟随模式**：
  - 关闭：不跟随
  - 粘人：慢慢跟着你，离远会小跑过来
  - 胆小：快挪鼠标会躲开，停下会凑过来

### 系统感知
- **总开关**：启用/禁用所有系统感知功能
- **闲置检测**：键鼠闲置自动入睡
- **窗口感知**：全屏/编辑器/浏览器检测
- **负载感知**：CPU 负载检测
- **剪贴板感知**：复制文本提示
- **时间感知**：昼夜节律

### AI 对话
- **AI 开关**：启用/禁用 AI 对话功能
- **服务商**：DeepSeek/豆包/OpenAI/自定义
- **API 配置**：填写 API 地址、密钥、模型名称
- **上下文**：是否发送本地状态作为上下文

### 桌面与快捷键
- **智能避让**：自动避开窗口
- **随机闲逛**：空闲时走动
- **角落锁定**：固定在屏幕角落
- **全局快捷键**：自定义快捷键
- **开机自启**：登录时自动运行

## 🎨 技术架构

### 核心技术
- **GUI 框架**：PyQt6
- **动画引擎**：QMovie（即用即弃策略）
- **系统调用**：ctypes（Windows API）
- **网络请求**：requests（仅 AI 功能使用）
- **配置管理**：JSON 本地存储


### 性能优化
- **内存管理**：即用即弃的 GIF 加载，定期垃圾回收
- **帧率控制**：根据系统负载动态调整动画速度
- **事件驱动**：低频定时器（50ms 移动/1s 状态/2s 感知）
- **资源释放**：窗口关闭时立即释放资源

## 📖 使用指南

### 日常互动
1. **摸头**：左键单击宠物头部
2. **抱起**：长按拖拽到想要的位置
3. **对话**：中键点击打开对话窗口
4. **喂食**：托盘菜单 → 喂食
5. **玩游戏**：托盘菜单 → 小游戏

### 状态说明
- **心情**：影响宠物的活跃度，通过互动提升
- **体力**：影响宠物的活动能力，通过喂食恢复
- **睡眠**：闲置时自动入睡，动键鼠即醒

### 高级功能
1. **AI 对话**：设置 → AI 对话 → 填写 API 信息
2. **自定义指令**：在对话中输入"变大"、"躲猫猫"等
3. **快捷键设置**：设置 → 桌面/快捷键 → 自定义快捷键
4. **角落锁定**：设置 → 桌面/快捷键 → 固定位置

## ❓ 常见问题

### Q: 宠物不显示怎么办？
A: 检查托盘图标，右键选择"显示"；或按快捷键 Ctrl+Alt+D。

### Q: 内存占用过高？
A: 在设置中调低动画帧率到"省电"模式。

### Q: AI 对话无法使用？
A: 确保在设置中正确填写了 API 地址和密钥。

### Q: 如何添加新角色？
A: 在 pets 目录下创建新文件夹，按现有角色结构组织素材。

### Q: 支持多屏幕吗？
A: 支持，宠物可以在所有屏幕间自由移动。

### Q: 如何完全卸载？
A: A: 直接卸载程序即可，卸载后无任何残留文件及注册表。
